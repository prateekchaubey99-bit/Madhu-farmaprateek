# Madhu Farm Website

A dairy shop website for Madhu Farm, Gorakhpur. Customers can browse ghee, milk, paneer and butter, add items to a cart, and send the order on WhatsApp.

Live site: https://prateekchaubey99-bit.github.io/Madhu-farmaprateek/

## Features
- Product list with category filter
- Shopping cart with total price
- Order on WhatsApp
- Sell your dairy form
- Works on phones

## Built with
HTML, CSS, JavaScript
